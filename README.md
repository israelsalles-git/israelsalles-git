## 👋 Olá, mundo!

Sou desenvolvedor com base sólida em **Python/Django** e experiência prática no universo **fiscal e tributário brasileiro**. Hoje foco em construir uma carreira como **QA Automation Engineer**, unindo código, qualidade e conhecimento de negócio.

- 🎯 **Objetivo:** vaga de QA Automation Engineer
- 🧾 **Diferencial:** lido no dia a dia com XMLs de NF-e/NFC-e, CFOP, CSOSN/CST e CEST, ou seja, sei *o que* testar quando o assunto é compliance
- 🧪 **Construindo:** projeto de automação de testes para o portfólio (veja abaixo)
- 📱 **Explorando:** apps mobile com Flutter e Dart
- 🌱 **Sempre aprendendo:** metodologias ágeis, CI/CD e boas práticas de teste

## 🚀 Projeto em destaque

### 🤖 PDV Online Automation

Framework de automação de testes para um PDV online, seguindo padrões usados na indústria.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Pytest](https://img.shields.io/badge/Pytest-0A9EDC?style=flat-square&logo=pytest&logoColor=white)
![Selenium](https://img.shields.io/badge/Selenium-43B02A?style=flat-square&logo=selenium&logoColor=white)
![GitHub Actions](https://img.shields.io/badge/CI%2FCD-2088FF?style=flat-square&logo=githubactions&logoColor=white)

- ✅ Testes de **API** e **UI** com Page Object Model
- 🧾 **Validação de XML de NFC-e**, que une QA e conhecimento fiscal
- ⚙️ Pipeline de CI/CD rodando os testes automaticamente a cada push

👉 [Ver repositório](https://github.com/israelsalles-git/pdv-online-automation)
